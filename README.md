# 전라북도 관광지 추천 웹 플랫폼
전라북도 관광지의 활성화를 위한 웹 플랫폼 프로젝트입니다. <br /> 
## 📝프로젝트 소개
공공데이터 및 구글 리뷰 데이터를 기반으로 분석하여, 이용자에게 관광지 및 여행코스를 추천하도록 구현하였습니다.

-----

# 📌주요기능
### 지역/테마별 인기 여행지 추천 시스템 <br />
공공데이터 API (한국관광공사_관광정보)와 크롤링한 Google Maps 리뷰 데이터를 형태소 분석 및 감성 분석 (점수화)하여 각각 지역/테마별 필터링하여 인기순으로 추천하는 기능을 구현하였습니다.
